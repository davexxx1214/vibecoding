🎤 VibeKnowledge Hackathon Pitch (2025)

Each slide now has one short English paragraph you can read naturally.

## Slide 1 – Title & Vision
“Hi everyone, we are VibeKnowledge. Modern repos are huge, and even AI assistants get lost. Our VS Code plugin maps the codebase into an intelligent knowledge network so developers and AI share the same context.”

## Slide 2 – System Overview
“The product stands on three pillars: an interactive knowledge graph, deep AI collaboration, and a built-in RAG engine. It is 5k+ lines of TypeScript, runs locally on SQLite, and keeps data private.”

## Slide 3 – AI Collaboration
“We convert dependency data into clean Markdown and JSON notes. Cursor and Copilot read those notes, so they stop guessing and start understanding the real architecture.”

## Slide 4 – Entities, Relations, Observations
“Inside VS Code we manage entities, relations, and observations. Observations are sticky notes about bugs or decisions, so human knowledge lives next to the code.”

## Slide 5 – Interactive Graph
“The graph view is live. You can drag nodes, add links, or delete noise. New teammates grasp the system in seconds because they see the real connections.”

## Slide 6 – Export & Automation
“One click generates project reports, tech-stack detection, .cursorrules, and Copilot instructions. Developers save hours of manual prompt writing.”

## Slide 7 – RAG + Gemini
“We support 100+ document formats, embed them into a vector store, and call Google Gemini to answer questions with accurate citations.”

## Slide 8 – Persistent Knowledge Base
“Knowledge survives restarts. Auto-indexing keeps cloud data fresh, and each project has its own isolated store so nothing leaks between teams.”

## Slide 9 – Command Palette
“Over twenty commands live in the VS Code palette. You can run every feature without leaving the keyboard, which feels natural to developers.”

## Slide 10 – Technical Architecture
“SQLite plus TypeScript form the base, the extension core sits in the middle, and on top we connect to Gemini, Cursor, and Copilot. The layers keep the system stable and maintainable.”

## Slide 11 – MCP Integration
“Our MCP server exposes `knowledge://overview`, `search_entities`, `search_observations`, `knowledge://relations`, and `ask_question`. Cursor and Copilot now query the graph just like a teammate.”

## Slide 12 – Closing
“VibeKnowledge turns messy code into a clear network for both humans and AI. Thank you for your time—happy to take your questions.”
