⚡ 3 步快速开始
================================================================================

1️⃣  按 F5 键启动调试
     → 会打开一个新的 VS Code 窗口

2️⃣  在新窗口中打开任意项目文件夹
     → 必须是文件夹，不能是单个文件

3️⃣  选中一段代码，右键选择：
     "Knowledge: Create Entity from Selection"
     → 创建你的第一个知识节点！

================================================================================
🎯 核心功能演示
================================================================================

【创建实体】
  1. 选中函数/类名
  2. 右键 → "Knowledge: Create Entity from Selection"
  3. 输入名称、选择类型、添加描述

【添加观察】
  1. 光标放在实体上
  2. 右键 → "Knowledge: Add Observation to Entity..."
  3. 输入笔记（如"性能问题：需要优化"）

【查看信息】
  - 鼠标悬停在代码上 → 显示实体信息
  - 查看 CodeLens → 代码上方显示统计
  - 点击左侧 🧠 图标 → 浏览所有实体

【搜索】
  - Ctrl+Shift+P → "Knowledge: Search Graph"
  - 输入关键词 → 快速查找实体

🐛 遇到问题？
================================================================================

【插件没激活】
  → 确保打开了文件夹（不是单个文件）
  → 查看开发者工具：Help → Toggle Developer Tools

【数据库错误】
  → 检查目录权限
  → 删除 .vscode/.knowledge/graph.sqlite 重试

【编译错误】
  → rm -rf node_modules dist
  → npm install
  → npm run compile
